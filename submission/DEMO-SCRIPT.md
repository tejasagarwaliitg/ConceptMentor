# Athena — 3-minute demonstration

**Team:** Athena · **Member:** Tejas Agarwal

## 0:00–0:20 · The problem
“A wrong answer tells you something went wrong. It does not tell you whether you missed an earlier concept, chose the wrong model, or misunderstood the question. Concept Mentor checks a possible explanation and gives you a focused next step.”

## 0:20–0:45 · A welcoming start
Show the light profile screen, enter as a guest, and point out the chapter picker and concept map. State that this is a local demonstration with unapproved draft questions. The simulated profile is labelled; do not pass it off as a learner study.

## 0:45–1:40 · Find a contributing concept
Start Vector components. Select an incorrect changed-context answer, then the correct standard answer. Answer the foundation checks correctly. Show the suspected contributing gap and the supporting evidence. Open the repair screen and complete its independent question. Point to “Immediate check passed; retention untested.”

Because answer options are shuffled, use the working in QUESTION-REVIEW.md rather than remembering button positions. The demo is an illustrative route, not a claim about a real learner.

## 1:40–2:05 · See the connections
Open Concept map. Select Vector components. Blue identifies its prerequisites; green identifies later dependent concepts. The vertical order remains fixed while dragging horizontally. A graph edge suggests a possible learning route; it does not prove causation.

## 2:05–2:25 · Revisit later
Show the review schedule. A repair starts at one day. Later reviews move through 1, 3, 7, 14, 30, 60 and 120 day buckets using correctness and confidence. If using the demo clock, explicitly say the elapsed time is simulated. Every shown question is excluded from future requests. The current pool has only one B2 item per concept; if no fresh item is available, the review stops without changing evidence. More reviewed variants are needed.

## 2:25–2:45 · Cline and the implementation
“Cline’s SDK integration offers bounded tool suggestions; grading and progress are controlled by code. There is a deterministic fallback.” Do not claim a successful live Cline call unless it has been verified after credentials are configured. Show the architecture and test evidence instead.

## 2:45–3:00 · What comes next
“The next gate is human question review and observing an adult learner use the journey. Then we can add fresh review variants and evaluate whether a repair lasts. We are not claiming proven learning gains.”
