<objective>
Build the curated video foundation: a pure deterministic ranker plus URL builder in `lib/videos.ts`, the builder-curated allowlist in `content/resources.ts` (15 channels, max 2 videos on each of the 4 demo-path nodes), and the test harness in `tests/resources.test.ts` that gates every catalog change. Implements D-01, D-02, D-03, D-04 (catalog + ordering) and D-12-part (code ranks videos).

Purpose: Everything downstream (Repair card, Settings picker, hasVideo plumbing, nudge) reads this catalog and ranker. Getting the trust boundary right here — IDs only in content, URLs built in one validated place, ranking weights never displayed — is what makes YT-03 hold.

Output: Three new files; `npx vitest run tests/resources.test.ts` green from `app/`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| builder content → browser | resources.ts ships reviewed IDs; untrusted if edited without running the gate test |
| model → UI | model output must never flow into video links (no tool returns URLs; ranker input is tags/IDs only) |
| browser URL bar | built links leave the app; host allowlist + noopener link pattern contain tab-nabbing and lookalike hosts |
